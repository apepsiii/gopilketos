video_camera_front Bilik Kiosk & Sinkronisasi Google Drive

Video Booth

Konfigurasi perekaman video ucapan/kesan & pesan dari bilik kiosk siswa, penyimpanan lokal, serta sinkronisasi otomatis ke Google Drive agar tidak membebani kapasitas server.

Izinkan pemilih merekam video kesan & pesan melalui halaman /kiosk.

Jika tidak dicentang, video baru masuk ke antrean moderasi admin terlebih dahulu.

Video yang diunggah ke server lokal akan otomatis disinkronkan ke Google Drive di latar belakang menggunakan Service Account.

Setelah file video terunggah sempurna ke Google Drive, file lokal di server dihapus otomatis untuk menghemat ruang disk.

ID folder tujuan penyimpanan video di Google Drive (didapat dari URL folder drive, misal: drive.google.com/drive/folders/<FOLDER_ID>). Pastikan folder dibagikan (share) dengan email Service Account sebagai Editor.

Salin dan tempel (paste) seluruh isi file JSON kredensial Google Service Account yang diunduh dari Google Cloud Console.
